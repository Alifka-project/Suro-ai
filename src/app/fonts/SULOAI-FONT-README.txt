SULOAI Font Family — TTF + WOFF2
==================================
- SULOAI-Light / Regular / Medium / Bold (.ttf + .woff2)
- suloai-font.css -> @font-face sẵn dùng, copy vào project
- preview.html -> mở bằng browser để xem trước

Nền tảng: Saira (Google Fonts, giấy phép SIL OFL - miễn phí, được phép
chỉnh sửa/đổi tên/dùng thương mại). Đã export 4 static weight riêng
(Light 300 / Regular 400 / Medium 500 / Bold 700) và đổi metadata
thành "SULOAI".

Dùng: font-family: 'SULOAI', sans-serif;
